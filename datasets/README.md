# Dataset

Este projeto utiliza o dataset **IBM HR Analytics Employee Attrition & Performance**.

- Fonte: [Kaggle - IBM HR Analytics Attrition Dataset](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)
- Formato original: CSV
- Registros: 1.470
- Colunas: 35

## Como obter
1. Acesse o link acima
2. Faça o download do arquivo `WA_Fn-UseC_-HR-Employee-Attrition.csv`
3. Coloque o arquivo em uma pasta local (fora do OneDrive, se estiver usando SQL Server localmente) para executar o script `01_bronze_staging.sql`
