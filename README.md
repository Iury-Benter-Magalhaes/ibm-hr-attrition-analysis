# ibm-hr-attrition-analysis

Limpeza de dados e análise exploratória em SQL sobre o dataset IBM HR Analytics, 
com foco em identificar os principais fatores por trás da rotatividade (attrition) de funcionários.
Inclui um dashboard em Power BI para visualização dos principais insights.

## Objetivo
Identificar quais fatores mais influenciam a saída de funcionários da empresa,
gerando insights que poderiam apoiar decisões de RH para reduzir o turnover.

## Dataset
IBM HR Analytics Employee Attrition & Performance
- ~1470 registros, 35 colunas
- Fonte:https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

## Ferramentas
- SQL Server
- Power BI

## Estrutura do Projeto
1. Limpeza de Dados (Data Cleaning)
2. Análise Exploratória
3. Perguntas de Negócio
4. Dashboard Power BI
5. Insights e Conclusões

## Perguntas de Negócio
- Qual o percentual geral de attrition e por departamento/cargo?
- Funcionários que fazem hora extra (overtime) saem mais?
- Existe relação entre satisfação no trabalho e attrition?
- Funcionários mais jovens ou com menos tempo de empresa saem mais?
- Salário baixo está ligado a mais saídas?
- Distância de casa até o trabalho influencia o attrition?
